# Шаблон ценников

HTML-шаблон A4 с двумя редактируемыми ценниками.

## Как открыть

Откройте `index.html` в браузере.

## Возможности

- два ценника на листе A4;
- редактирование проекта, технологии, комплектации, цены и даты;
- выбор инженерных коммуникаций: входит / не входит;
- QR-код по проекту с возможностью заменить через кнопку `обновить`;
- печать или сохранение в PDF через кнопку `Печать / PDF`.
